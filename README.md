
# CzechMidi-QoL

Czech translation of Midi-QoL version 13.0.8

## Popis
Tento modul poskytuje českou lokalizaci pro Midi-QoL verze 13.0.8. Obsahuje překlady základních textů aplikace.

## Instalace
Pro instalaci modulu obvyklým upůsobem můžeš použít následující odkaz ve Foundry VTT:

```
https://raw.githubusercontent.com/Lethrendis/CzechTranslationMidi/main/module.json
```
